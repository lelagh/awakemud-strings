You can use all the usual MUD colours, typing enter will create a new line in the preview area for things like descriptions, rooms and the like. The preview text and colours will be updated in real time, but depending on your client, browser, monitor, etc, the preview might (probably might) look slightly different compared to how it would appear in-game (in Mudlet, and so on). Clicking any of the codes will copy them into the input box wherever the current position of the cursor is. If any text is currently selected, it will be replaced. If you double click the input text to only highlight a Fxxx code and click a code below, it should just replace the code without adding extra ^[ ] characters.
